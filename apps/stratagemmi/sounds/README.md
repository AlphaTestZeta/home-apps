# Suoni degli stratagemmi

Carica qui i file audio, con questi nomi esatti:

- `public_audio_sounds_stratagem-input-beep-1.ogg` … `-8.ogg` — a ogni swipe, uno a caso
- `public_audio_sounds_stratagem-input-fail-1.ogg` e `-2.ogg` — combinazione sbagliata, uno a caso
- `public_audio_sounds_stratagem-input-ready.ogg` — stratagemma completato (al posto del beep dell'ultimo swipe)
