# Suoni degli stratagemmi

Carica qui gli 8 beep, con questi nomi esatti:

- `public_audio_sounds_stratagem-input-beep-1.ogg`
- `public_audio_sounds_stratagem-input-beep-2.ogg`
- ...
- `public_audio_sounds_stratagem-input-beep-8.ogg`

A ogni swipe ne parte uno a caso (mai lo stesso due volte di fila).
Per cambiare quantità o nome dei file: costanti `BEEP_COUNT` e `beepSrc` in `../app.js`.
